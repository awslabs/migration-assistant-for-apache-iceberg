# Frontend

React + TypeScript portal for the Migration Assistant. Built with Vite, TanStack Router, and TanStack Query.

## Setup

```bash
npm install
npm run dev
```

Runs on http://localhost:5173. Proxies API calls to the backend on port 8000.

## Build

```bash
npm run build
```

Output goes to `dist/`.
