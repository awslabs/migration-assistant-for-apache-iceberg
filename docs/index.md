# Migration Assistant for Apache Iceberg

<p class="ib-tagline">A planned and paved path to adopting Iceberg at scale on AWS</p>

Convert existing data lake tables into Amazon S3 Tables or self-managed Apache Iceberg.
Plan, analyze, run and monitor migrations from one web portal, with an AI agent that
recommends a strategy for each table.
