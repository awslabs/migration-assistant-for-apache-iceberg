# Contributing to Migration Assistant for Apache Iceberg

Thank you for your interest in Migration Assistant for Apache Iceberg!

## Reporting Bugs/Feature Requests

At this time, we are not accepting pull requests for this repository. It is maintained by an AWS development team.

However, we welcome you to use the GitHub issue tracker to report bugs or suggest features.

- **Bug reports:** open a [GitHub issue](https://github.com/awslabs/migration-assistant-for-apache-iceberg/issues) describing what you expected, what happened, and how to reproduce it.
- **Feature requests and feedback:** open a [GitHub issue](https://github.com/awslabs/migration-assistant-for-apache-iceberg/issues) describing your use case.

We read every issue and use them to shape the roadmap. We may accept pull requests in the future.

When filing an issue, please check existing open issues first, and include as much of the following as you can:

- A reproducible test case or series of steps
- The version you are using (the [`VERSION`](VERSION) file, or the release tag)
- Anything unusual about your environment or deployment

## Code of Conduct
